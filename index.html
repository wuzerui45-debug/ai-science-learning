机器是怎么
认出一只猫的？

先给一个简短的答案，再用五讲把这件事讲清楚：机器不是靠人把规则写死，而是从大量例子里总结出规律。

  • 它认出的不是「猫」这个概念，而是一堆相似特征的统计结果。
  • 所以它也会认错，会受例子的影响——第四讲专门讲这件事。
  • 它也常常帮得上忙：认脸、听写、看片子、找路——第三讲讲用途。

    关于项目

    一份知识，两种表达

    一个面向不同人群的人工智能基础知识交互科普原型：儿童探索模式与老年友好模式共享同一套科学内容，用不同的语言、字号、颜色和交互方式重新表达。

    项目设计理念

    「一份知识，两种表达」关注不同人群在理解科学知识时的差异。项目以人工智能基础知识为内容，通过儿童探索模式和老年友好模式，将同一知识体系转化为不同的学习体验。

    知识本身不需要被简化成两个版本，需要改变的是讲述方式：给孩子的版本多用生活比喻和短句子，给长辈的版本用更大的字、更高的对比和更慢的节奏。两种表达指向同一个科学结论，也共享同一份知识框架。

    项目设计目标

    • 降低人工智能基础知识的理解门槛，让没有技术背景的人也能听懂。
    • 通过互动学习增强知识理解，把「看」变成「判断」和「回答」。
    • 关注儿童的认知特点：短句子、多比喻、即时鼓励、一次一个重点。
    • 关注老年人的阅读和操作体验：大字、高对比、大按钮、不限时。
    • 探索数字媒体技术在科普教育中的应用，验证双模式设计的可行性。
    • 坚持科学准确：不夸大人工智能的能力，不把它描述成有思想的存在。

    两种模式的差异

    不只是换颜色，从文字到交互都有区别

    儿童探索模式

    • 引导角色「小问」用一句对话提出思考问题。
    • 每个知识步骤只讲一个重点，句子短、比喻多。
    • 场景练习是「翻卡片」的探索形式，点开才知道答案。
    • 测验一次只出现一道题，答对即时得到鼓励。

    老年友好模式

    • 正文默认 20px，可用「大字阅读」放大到 25px。
    • 深色文字配暖纸白底，细线与边框更清楚，按钮更大。
    • 场景练习以清单列出，结论用文字写明「用 / 没用 / 看情况」。
    • 测验三道题一次列清，不限制时间、不自动跳转。

    内容与技术说明

    • 内容来源：课程文字、生活案例与题目均由作者根据人工智能基础知识编写，属于预设科普内容，页面上不进行任何实时内容生成。
    • 技术实现：单个 HTML 文件，使用 HTML、CSS 与原生 JavaScript，不使用任何前端框架，不需要后端、数据库或登录注册。
    • 离线可用：不使用外部图片、外部字体和外部脚本，全部视觉元素由 CSS 与内嵌 SVG 绘制，断网状态下也能正常打开。
    • 进度保存：学习进度保存在当前浏览器的 localStorage 中，不涉及账号和服务器，也不会上传任何个人信息。
    • 科学表述：课程中不使用「人工智能有思想、有感情」这类说法，统一描述为「从大量例子中总结规律」，并明确说明它可能出错。
